# Security Policy

The **brand-kit** team takes security seriously.  
We appreciate responsible disclosure and coordinated vulnerability reporting.

---

## Supported Versions

Only the **latest major version** of brand-kit is actively supported with security updates.

| Version | Supported |
|-------|-----------|
| Latest | ✅ |
| Older | ❌ |

---

## Reporting a Vulnerability

If you believe you have found a security vulnerability, **please do not open a public issue**.

Instead, report it privately using one of the following methods:

- **Email:** security@frontal.dev  
- **Private Security Advisory:** via GitHub Security Advisories (preferred)

Please include:
- A clear description of the vulnerability
- Steps to reproduce (proof-of-concept if possible)
- Impact assessment (what could be exploited)
- Affected versions

---

## Response Timeline

We aim to follow this process:

- **Acknowledgement:** within 48 hours
- **Initial assessment:** within 5 business days
- **Fix & disclosure:** as quickly as reasonably possible

Timelines may vary depending on severity and complexity.

---

## Coordinated Disclosure

We kindly ask reporters to:
- Avoid public disclosure until a fix is released
- Give us reasonable time to investigate and mitigate the issue

We will:
- Credit reporters when appropriate
- Communicate clearly throughout the process

---

## Scope

This policy applies to:
- Source code in this repository
- Published packages
- Build and distribution artifacts

Out of scope:
- Vulnerabilities in third-party dependencies (please report upstream)
- Social engineering attacks
- Denial of service via traffic flooding

---

## Safe Harbor

We will not pursue legal action against individuals who:
- Act in good faith
- Follow this security policy
- Avoid privacy violations and data destruction

---

## Thanks

Security research and responsible disclosure help make brand-kit safer for everyone.  
Thank you for helping us improve.
